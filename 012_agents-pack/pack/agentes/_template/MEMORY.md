# Memory (estratégica)

Aprendizajes de largo plazo, alto-señal. Se lee cada sesión. Capturar → destilar → podar.

Qué va acá: verdades de arquitectura, patrones confirmados, modos de falla que ya
mordieron, decisiones del humano que no hay que volver a preguntar.

Qué **no** va acá: el registro de lo que hiciste ayer. Eso es un journal, y si lo mezclás
este archivo crece hasta que nadie lo lee — que es la única forma de que una memoria falle.
