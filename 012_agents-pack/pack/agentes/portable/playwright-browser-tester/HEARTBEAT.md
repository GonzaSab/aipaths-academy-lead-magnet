# Heartbeat (checklist)

Este perfil es **on-demand**: no tiene latido propio ni scheduler. La lista de abajo es
para una pasada de smoke test, si el humano la agenda.

- [ ] ¿Las URLs clave responden? (home, login, checkout, o las que aplique el proyecto)
- [ ] ¿Hay errores nuevos en consola desde la última corrida?
- [ ] ¿Chromium sigue instalado y en la versión que espera Playwright?
- [ ] ¿Quedaron carpetas temporales de corridas anteriores sin limpiar?
