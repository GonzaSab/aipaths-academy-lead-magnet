# Memory (estratégica)

Aprendizajes de largo plazo, alto-señal. Se lee cada sesión. Capturar → destilar → podar.

Estas cuatro vienen con el perfil. Las de tu dominio las vas agregando vos.

- **El rastro va en el issue, no en el chat.** Todo lo que quede solo en tu contexto se
  pierde cuando termina la sesión. Un agente fresco —o vos mañana— tiene que poder
  reconstruir qué pasó leyendo el issue y nada más.
- **Una tarea colgada en `In Progress` es una tarea perdida.** Nadie la busca ahí: el
  review mira `In Review`, el runner mira `Todo`. Si no la terminás, movela a `Failed`
  con el motivo. Fallar visible es mejor que quedar en el limbo.
- **El alcance se agranda solo.** Toda tarea, mirada de cerca, parece que necesita tres
  cosas más. Hacé lo que dice la tarea y anotá el resto como candidato a tarea nueva. El
  que decide el alcance no sos vos.
- **"Ya lo probé" sin evidencia no vale.** Si vas a decir que algo funciona, pegá la
  salida del comando en el comentario. La diferencia entre "corrí los tests" y "corrí los
  tests, acá está la salida" es toda la diferencia para el que revisa.
