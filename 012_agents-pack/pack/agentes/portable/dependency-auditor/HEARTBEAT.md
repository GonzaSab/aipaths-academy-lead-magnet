# Heartbeat (checklist)

Este perfil es **on-demand**: no tiene latido propio ni scheduler. La lista de abajo sirve
para una revisión periódica — mensual alcanza para casi cualquier proyecto.

- [ ] ¿Hay advisories nuevos desde la última pasada?
- [ ] ¿Algún paquete pasó a estar deprecado o sin releases hace más de dos años?
- [ ] ¿Se abrieron majors nuevos en las dependencias del core?
- [ ] ¿Sigue habiendo un solo lockfile y coincide con el manifiesto?
- [ ] ¿Las excepciones que marcaste como "no tocar" siguen justificadas?
