# Heartbeat (checklist)

Este perfil es **on-demand**: no tiene latido propio ni scheduler. La lista de abajo es
para una pasada periódica sobre lo que quedó abierto, si el humano la pide.

- [ ] ¿Hay PRs abiertos hace días sin review?
- [ ] ¿Algún review tuyo quedó con comentarios sin responder?
- [ ] ¿Se mergeó algo sin pasar por review? (`git log --merges`)
- [ ] ¿Hay ramas viejas con trabajo sin integrar que ya no compilan contra main?
