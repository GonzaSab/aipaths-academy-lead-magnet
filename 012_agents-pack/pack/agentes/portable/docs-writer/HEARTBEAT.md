# Heartbeat (checklist)

Este perfil es **on-demand**: no tiene latido propio ni scheduler. La lista de abajo es
para una revisión periódica de la doc, si el humano la pide.

- [ ] ¿Los comandos del README siguen existiendo en los scripts o el Makefile?
- [ ] ¿Aparecieron variables de entorno nuevas en el código que no están documentadas?
- [ ] ¿Hay docs que citan rutas, archivos o features que ya no existen?
- [ ] ¿El README menciona una versión de runtime distinta a la que usa el CI?
- [ ] ¿Quedaron "TODO: completar" de alguna pasada anterior?
