# Prompts de Social Media y Publicidad

> Prompts gratis para contenido de social media y publicidad pagada. Sources: [WebFX](https://www.webfx.com/blog/ai/ai-prompt-examples/), [StoryChief](https://storychief.io/blog/ai-marketing-prompts), [Juma](https://juma.ai/blog/chatgpt-prompts-for-marketing)

## Contenido de Social Media

### Posts Específicos por Plataforma
```
Crea 5 posts de social media sobre [TEMA/PRODUCTO] para [PLATAFORMA].

Especificaciones de plataforma:
- LinkedIn: Profesional, 150-300 palabras, liderazgo de pensamiento
- Twitter/X: Directo, menos de 280 caracteres, digno de hilo
- Instagram: Primero visual, caption 125-150 palabras, sugerencias de hashtags
- TikTok: Consciente de tendencias, casual, enfocado en gancho

Incluye:
- Línea de gancho/apertura
- Mensaje principal
- Call-to-action
- Hashtags relevantes (para IG/TikTok)
```

### Generador de Calendario de Contenido
```
Crea un calendario de contenido de social media de 2 semanas para [TIPO DE NEGOCIO].

Plataformas: [PLATAFORMAS]
Frecuencia de publicación: [X posts por plataforma por semana]

Para cada post incluye:
- Día y plataforma
- Tipo de contenido (educacional/promocional/engagement/entretenimiento)
- Tema/temática
- Borrador de caption
- Sugerencia visual
- Mejor hora de publicación

Balance: 80% valor, 20% promocional
```

### Generador de Ganchos Virales
```
Genera 10 ganchos que detengan el scroll para [TEMA/NICHO] en [PLATAFORMA].

Tipos a incluir:
- Opinión controvertida
- Estadística sorprendente
- Apertura de historia personal
- Pregunta que resuena
- "La mayoría de la gente no sabe..."
- Desafío/llamada de atención
- Configuración antes/después

Mantén menos de 15 palabras cada una. Alto factor de curiosidad.
```

## Contenido de Video

### Script de Video de Forma Corta
```
Escribe un script de video de forma corta (menos de 60 segundos) para [PLATAFORMA: TikTok/Reels/Shorts].

Tema: [TEMA]
Objetivo: [educar/entretener/vender]

Estructura:
- Gancho (0-3 seg): Detener el scroll
- Configuración (3-10 seg): Contexto
- Valor/Historia (10-45 seg): Contenido principal
- CTA (45-60 seg): Qué hacer después

Incluye:
- Señales de texto en pantalla
- Sugerencias de audio/música
- Notas de transición visual
```

### Esquema de Video de YouTube
```
Crea un esquema de video de YouTube para: "[TÍTULO DEL VIDEO]"

Largo objetivo: [X] minutos
Audiencia: [AUDIENCIA OBJETIVO]

Incluye:
- Script de gancho (primeros 30 segundos)
- Desglose de capítulos con cronograma
- Puntos clave por sección
- Sugerencias de B-roll/visual
- CTA de pantalla final
- Borrador de descripción con palabras clave
- 10 alternativas de título
```

## Publicidad Pagada

### Anuncios Facebook/Meta
```
Escribe 3 variaciones de copy para anuncios de Facebook para [PRODUCTO/SERVICIO].

Detalles:
- Oferta: [DETALLES DE OFERTA]
- Audiencia objetivo: [DEMOGRAFÍA, INTERESES]
- Objetivo: [leads/ventas/conciencia]

Para cada variación proporciona:
- Texto principal (125 caracteres ideal)
- Título (40 caracteres)
- Descripción (30 caracteres)
- Recomendación de botón CTA

Ángulos: 1) Punto de dolor, 2) Enfocado en beneficio, 3) Prueba social
```

### Copy de Google Ads
```
Genera copy para Google Ads para la palabra clave "[PALABRA CLAVE OBJETIVO]"

Crea:
- 5 títulos (máx. 30 caracteres cada uno)
- 3 descripciones (máx. 90 caracteres cada una)
- Sugerencias de ruta de URL de visualización

Landing page: [URL/DESCRIPCIÓN]
Propuestas únicas de venta: [USP 1, 2, 3]
Audiencia objetivo: [AUDIENCIA]
```

### Anuncios LinkedIn
```
Crea copy de anuncios de LinkedIn para [PRODUCTO/SERVICIO B2B].

Audiencia: [TÍTULOS DE TRABAJO, INDUSTRIAS]
Objetivo de campaña: [generación de leads/conciencia/conversiones]

Proporciona:
- Texto de introducción (máx. 150 palabras)
- Opciones de título (3)
- Variaciones de CTA
- Sugerencias de targeting

Tono: Profesional pero no aburrido
Incluye: Punto de dolor específico, propuesta de valor clara, elemento de credibilidad
```

## Influencers y UGC

### Brief Creativo de Influencer
```
Crea un brief creativo para colaboración con influencers.

Marca: [NOMBRE DE MARCA]
Producto: [PRODUCTO]
Objetivo de campaña: [OBJETIVO]
Plataforma: [PLATAFORMA]

Incluye:
- Mensajes clave (máx. 3)
- Menciones/hashtags requeridos
- Qué hacer y qué no hacer
- Sugerencias de formato de contenido
- Puntos de conversación
- Requisitos de divulgación
```

### Script de Anuncio UGC
```
Escribe un script de anuncio estilo UGC para [PRODUCTO].

Formato: Testimonial auténtico, primera persona
Largo: 30-45 segundos
Plataforma: [PLATAFORMA]

Estructura:
- Gancho de atención (problema/momento relatable)
- Historia de descubrimiento
- Demostración/características del producto
- Resultados/transformación
- Recomendación + CTA

Tono: Natural, apariencia no guionada
```
