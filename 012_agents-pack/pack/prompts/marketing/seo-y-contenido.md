# Prompts de Contenido SEO

> Prompts gratis para creación y optimización de contenido SEO. Sources: [HubSpot](https://blog.hubspot.com/marketing/ai-prompt-examples), [Glean](https://www.glean.com/blog/ai-prompts-for-marketing), [Founderpath](https://founderpath.com/blog/ai-prompt-marketing-business)

## Planificación de Contenido de Blog

### Esquema Detallado de Blog
```
Crea un esquema detallado para un artículo de 1.500 palabras dirigido a la palabra clave '[PALABRA CLAVE OBJETIVO]'.

Incluye:
- Sugerencias de encabezados H2 y H3
- Estadísticas potenciales para investigar
- Un enfoque de introducción atractivo
- Puntos clave a cubrir en cada sección
- Una conclusión fuerte con CTA

Audiencia objetivo: [AUDIENCIA]
Tono: [informativo/conversacional/profesional]
```

### Generación de Artículos de Blog SEO
```
Escribe un artículo de blog de 1.500 palabras titulado '[TÍTULO]'.

Requisitos:
- Audiencia objetivo: [TIPO DE AUDIENCIA]
- Tono: informativo y atractivo
- Incluye estas palabras clave naturalmente: [LISTA DE PALABRAS CLAVE]
- Estructura con H2s y H3s
- Añade un gancho de introducción atractivo
- Incluye conclusiones accionables
- Termina con un CTA claro
```

### Ideas de Temas para Palabras Clave
```
Sugiere 10 temas de artículos de blog que clasificarían bien para la palabra clave '[PALABRA CLAVE]'.

Para cada tema proporciona:
- Título sugerido (máx. 60 caracteres)
- Intención de búsqueda (informacional/transaccional/navegacional)
- Puntos clave a cubrir
- Palabras clave secundarias potenciales
```

## Meta Descripciones y Títulos

### Generador de Meta Descripciones
```
Escribe 3 meta descripciones amigables para SEO para un artículo sobre [TEMA].

Requisitos:
- 150-160 caracteres cada una
- Incluye la palabra clave principal: [PALABRA CLAVE]
- Incluye una propuesta de valor clara
- Añade un elemento de urgencia o curiosidad
- Incluye un CTA sutil
```

### Optimización de Títulos
```
Genera 10 títulos alternativos para este artículo: '[TÍTULO ACTUAL]'

Requisitos:
- Más atractivos manteniendo el valor SEO
- Palabra clave objetivo: '[PALABRA CLAVE OBJETIVO]'
- Mezcla de formatos: cómo hacer, listas, preguntas, palabras poderosas
- Mantén bajo 60 caracteres para visualización en SERP
```

## Investigación de Palabras Clave

### Generación de Lista de Palabras Clave
```
Genera una lista de 20 palabras clave de alto tráfico relacionadas con [TEMA] que podamos dirigir en contenido próximo.

Organiza por:
- Palabras clave primarias (alto volumen, competitivas)
- Palabras clave long-tail (volumen menor, más fácil de clasificar)
- Palabras clave basadas en preguntas (para featured snippets)
- Palabras clave de intención comercial (para conversiones)

Incluye intención de búsqueda estimada para cada una.
```

### Análisis de Brecha de Palabras Clave de Competidores
```
Estoy en el espacio [INDUSTRIA]. Mis principales competidores son [COMPETIDOR 1, 2, 3].

Sugiere palabras clave que probablemente clasifican y que debería dirigir, categorizadas por:
- Oportunidades de contenido informacional
- Oportunidades de página de producto/servicio
- Oportunidades de contenido de comparación
- Oportunidades de contenido FAQ
```

## Optimización de Contenido

### Auditoría de Contenido Existente
```
Analiza este contenido en busca de mejoras SEO:

[PEGA CONTENIDO]

Proporciona:
- Evaluación de densidad de palabras clave
- Sugerencias para mejor colocación de palabras clave
- Mejoras en la estructura de encabezados
- Oportunidades de enlace interno
- Brechas de contenido a abordar
- Mejoras de legibilidad
```

### Optimización de Featured Snippet
```
Reescribe este párrafo para optimizar para un featured snippet para la consulta '[CONSULTA]':

[PEGA PÁRRAFO]

Crea versiones para:
- Snippet de párrafo (40-60 palabras)
- Snippet de lista (pasos numerados)
- Snippet de tabla (si aplica)
```
