# Prompts de Investigación y Resumen

> Prompts gratis para síntesis de investigación, resumen y extracción de conocimiento. Sources: [Founderpath](https://founderpath.com/blog/top-ai-business-prompts), [ClickUp](https://clickup.com/blog/ai-prompt-templates/), [Juma](https://juma.ai/blog/ai-prompts-for-business)

---

## Resumen de Documentos

### Resumen Ejecutivo desde Reporte
```
Creá un resumen ejecutivo de este reporte/documento:

[PEGÁ EL DOCUMENTO O SECCIONES CLAVE]

Requerimientos de resumen:
- Largo: [100/250/500] palabras
- Audiencia: [EJECUTIVOS/EQUIPO/CLIENTES]
- Enfoque: [DECISIONES/INSIGHTS/ACCIONES]

Incluí:
- Hallazgos clave (3-5 puntos de bala)
- Puntos de datos críticos
- Recomendaciones
- Próximos pasos
- Advertencias o limitaciones
```

### Notas de Reunión a Ítems de Acción
```
Convertí estas notas de reunión en ítems de acción estructurados:

Reunión: [NOMBRE DE REUNIÓN]
Fecha: [FECHA]
Asistentes: [NOMBRES/ROLES]

Notas:
[PEGÁ LAS NOTAS SIN PROCESAR]

Extrae:
- Decisiones tomadas (con contexto)
- Ítems de acción (dueño, fecha límite, detalles)
- Preguntas abiertas/estacionamiento
- Puntos de discusión clave
- Necesidad de reunión de seguimiento
```

### Desglose de Documento Largo
```
Resumí este documento largo en un formato jerárquico:

[PEGÁ EL DOCUMENTO]

Proporciona:
1. Resumen de una oración
2. Temas clave (3-5)
3. Resumen de cada sección principal
4. Citas/puntos de datos importantes
5. Preguntas que genera
6. Relación con [CONTEXTO/PROYECTO]

Mantené el resumen total bajo [X] palabras.
```

## Síntesis de Investigación

### Síntesis de Investigación Multiuente
```
Sintetizá hallazgos de estas fuentes sobre [TEMA]:

Fuente 1: [RESUMEN/PUNTOS CLAVE]
Fuente 2: [RESUMEN/PUNTOS CLAVE]
Fuente 3: [RESUMEN/PUNTOS CLAVE]

Proporciona:
- Temas comunes entre fuentes
- Hallazgos conflictivos
- Brechas en la investigación
- Conclusiones más fuertemente respaldadas
- Áreas que necesitan más investigación
- Implicaciones prácticas

Pondera credibilidad de fuentes: [ALTA/MEDIA/BAJA para cada una]
```

### Estructura de Revisión de Literatura
```
Ayudame a estructurar una revisión de literatura sobre [TEMA].

Pregunta de investigación: [PREGUNTA]
Fuentes recolectadas: [CANTIDAD]
Período cubierto: [RANGO DE FECHAS]

Temas clave emergentes:
- [TEMA 1]
- [TEMA 2]
- [TEMA 3]

Creá:
- Marco de organización
- Esquema de secciones
- Lógica de transición entre secciones
- Prompts de análisis crítico
- Marco de identificación de brechas
- Enfoque de síntesis
```

### Análisis de Tendencias desde Artículos
```
Analiza estos artículos/reportes para identificar tendencias en [INDUSTRIA/TEMA]:

Fuentes:
1. [TÍTULO] - [FECHA] - [PUNTO CLAVE]
2. [TÍTULO] - [FECHA] - [PUNTO CLAVE]
3. [Continuar...]

Identificá:
- Tendencias emergentes (últimos 6-12 meses)
- Tendencias establecidas que continúan
- Tendencias en declive
- Señales contradictorias
- Predicciones para los próximos [PERÍODO]
- Implicaciones para [MI NEGOCIO/PROYECTO]
```

## Extracción de Información

### Extracción de Hechos Clave
```
Extrae hechos y figuras clave de este contenido:

[PEGÁ EL CONTENIDO]

Organizá en:
- Datos cuantitativos (números, porcentajes, fechas)
- Insights cualitativos (opiniones, predicciones)
- Entidades nombradas (personas, empresas, productos)
- Relaciones (X causa Y, A adquirió B)
- Líneas de tiempo (secuencia de eventos)

Marcá cualquier información incierta o conflictiva.
```

### Resumen de Documentación Técnica
```
Resumí esta documentación técnica para [AUDIENCIA: desarrolladores/managers/clientes]:

[PEGÁ LA DOCUMENTACIÓN]

Creá:
- Descripción general (qué hace esto)
- Capacidades clave
- Limitaciones/restricciones
- Prerrequisitos
- Guía de inicio rápido (condensada)
- Casos de uso comunes
- Trampas/advertencias

Nivel técnico: [PRINCIPIANTE/INTERMEDIO/EXPERTO]
```

### Extracción de Comparación
```
Extrae una comparación de este contenido:

[PEGÁ EL CONTENIDO COMPARANDO OPCIONES/PRODUCTOS/ENFOQUES]

Creá una comparación estructurada:
- Opciones siendo comparadas
- Criterios de comparación
- Puntuación/evaluación para cada una
- Pros y contras
- Recomendaciones de caso de uso
- Recomendación de la fuente (si la hay)
- Consideraciones faltantes

Formatea como tabla donde sea posible.
```

## Creación de Base de Conocimientos

### Generación de FAQ desde Contenido
```
Generá un documento FAQ a partir de este contenido:

[PEGÁ EL CONTENIDO: docs de producto, tickets de soporte, notas de reunión, etc.]

Creá [X] pares de Q&A cubriendo:
- Preguntas de entendimiento básico
- Preguntas de cómo hacer
- Preguntas de resolución de problemas
- Mejores prácticas
- Casos extremos

Para cada respuesta:
- Respuesta clara y concisa
- Link a sección de fuente
- Preguntas relacionadas
```

### Documentación de Proceso desde Notas
```
Convertí estas notas informales en documentación estructurada:

[PEGÁ NOTAS, MENSAJES DE SLACK, EMAILS sobre un proceso]

Creá:
- Nombre y propósito del proceso
- Instrucciones paso a paso
- Puntos de decisión
- Roles y responsabilidades
- Herramientas/sistemas utilizados
- Tips de la experiencia
- Errores comunes a evitar

Formatea para [WIKI/CONFLUENCE/NOTION]
```

### Constructor de Glosario
```
Creá un glosario a partir de este contenido para [AUDIENCIA]:

[PEGÁ EL CONTENIDO con términos específicos del dominio]

Para cada término:
- Definición simple
- Explicación extendida
- Ejemplo en contexto
- Términos relacionados
- Conceptos erróneos comunes

Organizá alfabéticamente.
Indicá nivel técnico: [BÁSICO/AVANZADO]
```

## Generación de Reportes

### Plantilla de Reporte de Investigación
```
Creá una estructura de reporte de investigación para [TEMA].

Objetivo de investigación: [OBJETIVO]
Audiencia: [QUIÉN VA A LEER]
Largo: [CANTIDAD DE PÁGINAS]

Secciones necesarias:
- Resumen ejecutivo
- Metodología
- Hallazgos
- Análisis
- Recomendaciones
- Apéndices

Para cada sección proporciona:
- Propósito
- Preguntas clave a responder
- Datos/evidencia a incluir
- Guía de largo
- Tips de formateo
```

### Automatización de Reporte Semanal/Mensual
```
Creá una plantilla para automatizar mi reporte [SEMANAL/MENSUAL] [TIPO DE REPORTE].

Stakeholders: [AUDIENCIA]
Fuentes de datos: [DE DÓNDE VIENEN LOS DATOS]

Proceso manual actual:
[DESCRIBÍ LOS PASOS ACTUALES]

Creá:
- Plantilla de estructura de reporte
- Métricas a auto-rellenar
- Prompts de comentario (completa-el-blanco)
- Recomendaciones de visualización
- Checklist de distribución
- Convención de nombres de archivo
```

### Resumen Listo para Cliente
```
Transformá este análisis interno en un resumen orientado al cliente:

Contenido interno:
[PEGÁ EL DOCUMENTO INTERNO]

Cliente: [TIPO DE CLIENTE/INDUSTRIA]
Relación: [NUEVO/EXISTENTE]
Propósito: [INFORMAR/PERSUADIR/REPORTAR]

Ajustá para:
- Remover jerga interna
- Agregar contexto que necesitan
- Destacar relevancia para ellos
- Nivel de detalle apropiado
- Tono profesional
- Próximos pasos/CTA claros

Largo: [CANTIDAD DE PALABRAS]
```

## Prompts Rápidos

### Generador de TLDR
```
Dame un TLDR de esto en [1-3] oraciones:

[PEGÁ CONTENIDO]

Enfoque en: [ASPECTO CLAVE]
Contexto de audiencia: [QUIÉN NECESITA ESTO]
```

### Resumen de Puntos de Bala
```
Resumí esto en [X] puntos de bala:

[PEGÁ CONTENIDO]

Cada punto debería:
- Ser auto-contenido
- Empezar con verbo de acción o sustantivo clave
- Ser menos de 20 palabras
- Cubrir un punto distinto
```

### Análisis de Implicaciones
```
¿Cuáles son las implicaciones de esta información?

[PEGÁ CONTENIDO]

Analiza implicaciones para:
- [STAKEHOLDER 1]
- [STAKEHOLDER 2]
- [MI ROL/NEGOCIO]

Incluí:
- Implicaciones inmediatas
- Implicaciones a largo plazo
- Riesgos
- Oportunidades
- Acciones requeridas
```
