# Prompts de Planificación de Tareas y Gestión de Proyectos

> Prompts gratis para desglose de tareas, planificación y productividad. Sources: [ClickUp](https://clickup.com/p/ai-prompts/strategic-business-analysis), [Learn Prompting](https://learnprompting.org/blog/ai-prompt-business-planning-strategy), [Juma](https://juma.ai/blog/ai-prompts-for-business)

---

## Desglose de Tareas

### Descomposición de Tarea Compleja
```
Desglosaá este proyecto en tareas accionables:

Proyecto: [NOMBRE DEL PROYECTO]
Objetivo: [OBJETIVO FINAL]
Timeline: [FECHA LÍMITE O DURACIÓN]
Tamaño del equipo: [CANTIDAD DE PERSONAS]
Restricciones: [PRESUPUESTO, RECURSOS, DEPENDENCIAS]

Proporciona:
1. Hitos principales (3-5)
2. Tareas bajo cada hito
3. Dependencias entre tareas
4. Esfuerzo estimado (S/M/L) para cada tarea
5. Secuencia sugerida/pistas paralelas
6. Items de riesgo a monitorear

Formatea como lista estructurada de tareas que pueda importar en [HERRAMIENTA DE PROYECTO].
```

### Asistente de Planificación de Sprint
```
Ayudame a planificar un sprint de [X] semanas para [EQUIPO/PROYECTO].

Objetivos de este sprint:
- [OBJETIVO 1]
- [OBJETIVO 2]
- [OBJETIVO 3]

Capacidad del equipo: [X] story points / [Y] horas
Items de carry-over: [LISTÁ SI LOS HAY]

Trabajo disponible:
- [FEATURE/TAREA 1]: [ESFUERZO ESTIMADO]
- [FEATURE/TAREA 2]: [ESFUERZO ESTIMADO]
- [Continuar...]

Proporciona:
- Alcance de sprint recomendado
- Priorización de tareas (MoSCoW)
- Evaluación de riesgo
- Dependencias a resolver primero
- Criterios de éxito para el sprint
```

### Planificación Diaria/Semanal
```
Ayudame a planificar mi [día/semana] basado en estos inputs:

Prioridades:
1. [DEBO HACER 1]
2. [DEBO HACER 2]
3. [DEBERÍA HACER 1]

Reuniones/compromisos:
- [HORA]: [COMPROMISO]
- [HORA]: [COMPROMISO]

Tiempo de enfoque disponible: [HORAS]
Patrón de energía: [madrugador/pico en la tarde/etc.]

Creá:
- Schedule bloqueado por tiempo
- Sugerencias de agrupamiento de tareas
- Asignación de tiempo buffer
- Límites de tareas realistas
- Checklist de revisión de fin de día
```

## Planificación Estratégica

### Marco OKR
```
Ayudame a crear OKRs para [EQUIPO/DEPARTAMENTO/EMPRESA].

Período: [TRIMESTRE/AÑO]
Misión empresarial: [MISIÓN]
Áreas de enfoque clave: [ÁREAS]

Desafíos actuales:
- [DESAFÍO 1]
- [DESAFÍO 2]

Para cada objetivo, proporciona:
- Declaración de objetivo (cualitativa, inspiradora)
- 3-4 Key Results (cuantitativos, medibles)
- Indicadores adelantados
- Iniciativas que apoyan cada KR
- Obstáculos potenciales

Formatea para organización [TAMAÑO DE EMPRESA].
```

### Creación de Roadmap
```
Creá un roadmap de producto/proyecto para [PROYECTO/PRODUCTO].

Visión: [VISIÓN A LARGO PLAZO]
Horizonte de tiempo: [6 meses/1 año/3 años]

Estado actual:
- [DÓNDE ESTAMOS AHORA]

Iniciativas clave:
- [INICIATIVA 1]
- [INICIATIVA 2]
- [INICIATIVA 3]

Restricciones:
- Presupuesto: [PRESUPUESTO]
- Equipo: [TAMAÑO]
- Dependencias: [DEPS EXTERNAS]

Proporciona:
- Enfoque por fases con temas por fase
- Hitos clave
- Visualización de dependencias
- Sugerencias de asignación de recursos
- Puntos de decisión go/no-go
```

### Matriz de Evaluación de Riesgos
```
Creá una evaluación de riesgos para [PROYECTO/INICIATIVA].

Alcance del proyecto: [DESCRIPCIÓN BREVE]
Timeline: [DURACIÓN]
Presupuesto: [MONTO]

Riesgos conocidos:
- [RIESGO 1]
- [RIESGO 2]

Para cada riesgo, analiza:
- Probabilidad (1-5)
- Impacto (1-5)
- Puntuación de riesgo (P × I)
- Estrategias de mitigación
- Planes de contingencia
- Dueño/responsable

También identifica riesgos que pudiera haber perdido basado en proyectos similares.
```

## Reuniones y Comunicación

### Generador de Agenda de Reunión
```
Creá una agenda para una reunión [TIPO DE REUNIÓN].

Propósito: [OBJETIVO DE REUNIÓN]
Duración: [TIEMPO]
Asistentes: [ROLES/PERSONAS]

Tópicos a cubrir:
- [TÓPICO 1]
- [TÓPICO 2]
- [TÓPICO 3]

Proporciona:
- Agenda con tiempos divididos por secciones
- Preguntas de discusión para cada tópico
- Items de preparación pre-reunión
- Resultados/decisiones esperadas
- Plantilla de ítems de acción
- Estructura de seguimiento
```

### Plantilla de Actualización de Estado
```
Creá una plantilla de actualización de estado para [PROYECTO/EQUIPO].

Audiencia: [STAKEHOLDERS]
Frecuencia: [DIARIA/SEMANAL/MENSUAL]

Incluí secciones para:
- Salud general (estado RAG)
- Logros principales
- Prioridades próximas
- Bloqueadores/riesgos
- Métricas/KPIs
- Pedidos/necesidades

Mantené [BREVE/DETALLADO] - aproximadamente [LARGO].
Incluí preguntas indicadoras para completar cada sección.
```

### Marco de Documento de Decisión
```
Creá un documento de decisión para: [DECISIÓN A TOMAR]

Contexto: [ANTECEDENTES]
Stakeholders: [QUIÉN ESTÁ INVOLUCRADO]
Timeline: [CUÁNDO SE NECESITA DECISIÓN]

Opciones siendo consideradas:
1. [OPCIÓN 1]
2. [OPCIÓN 2]
3. [OPCIÓN 3]

Estructura el documento:
- Declaración del problema
- Criterios de decisión (ponderados)
- Análisis de opciones
- Matriz de pros/contras
- Recomendación
- Plan de implementación
- Evaluación de reversibilidad
```

## Optimización de Procesos

### Análisis de Workflow
```
Analiza este workflow y sugerí mejoras:

Proceso actual:
1. [PASO 1] - [QUIÉN] - [TIEMPO]
2. [PASO 2] - [QUIÉN] - [TIEMPO]
3. [PASO 3] - [QUIÉN] - [TIEMPO]
[Continuar...]

Puntos de dolor:
- [PROBLEMA 1]
- [PROBLEMA 2]

Objetivos:
- Reducir tiempo por [X]%
- Reducir errores
- Mejorar handoffs

Proporciona:
- Identificación de cuellos de botella
- Oportunidades de automatización
- Opciones de procesamiento paralelo
- Candidatos a eliminación (pasos sin valor agregado)
- Workflow rediseñado
```

### Creación de SOP
```
Creá un Procedimiento Operativo Estándar para [PROCESO].

Nombre del proceso: [NOMBRE]
Propósito: [POR QUÉ EXISTE ESTO]
Frecuencia: [CON QUÉ FRECUENCIA]
Responsable: [ROL]

Pasos clave (nivel alto):
1. [PASO 1]
2. [PASO 2]
3. [PASO 3]

Proporciona:
- Instrucciones paso a paso detalladas
- Puntos de decisión con criterios
- Puntos de control de calidad
- Errores comunes y prevención
- Procedimientos de escalación
- Documentos/herramientas relacionados
- Sección de control de versión
```

### Planificación de Capacidad
```
Ayudame a planificar capacidad para [EQUIPO/RECURSO].

Estado actual:
- Tamaño del equipo: [CANTIDAD]
- Utilización actual: [%]
- Distribución de habilidades: [HABILIDADES]

Demanda próxima:
- [PROYECTO 1]: [ESTIMACIÓN DE ESFUERZO]
- [PROYECTO 2]: [ESTIMACIÓN DE ESFUERZO]
- [PROYECTO 3]: [ESTIMACIÓN DE ESFUERZO]

Restricciones:
- Presupuesto para contratación: [MONTO]
- Tiempo de ramp-up: [SEMANAS]
- Riesgo de attrition: [%]

Proporciona:
- Análisis de brecha de capacidad
- Recomendación de contratación vs outsourcing
- Identificación de brecha de habilidades
- Marco de priorización de trabajo
- Recomendaciones de buffer
```

## Investigación y Análisis

### Plantilla de Brief de Investigación
```
Creá un brief de investigación para investigar [TEMA].

Pregunta de investigación: [PREGUNTA PRINCIPAL]
Contexto empresarial: [POR QUÉ IMPORTA ESTO]
Decisión que esto informará: [DECISIÓN]

Alcance:
- En alcance: [QUÉ CUBRIR]
- Fuera de alcance: [QUÉ EXCLUIR]

Proporciona:
- Recomendación de metodología de investigación
- Sub-preguntas clave a responder
- Fuentes de datos a explorar
- Entrevistas con expertos a conducir
- Estimación de timeline
- Formato de entregable
```

### Marco de Análisis Competitivo
```
Creá un marco de análisis competitivo para [PRODUCTO/SERVICIO].

Nuestra oferta: [DESCRIPCIÓN BREVE]
Mercado objetivo: [SEGMENTO]

Competidores a analizar:
- [COMPETIDOR 1]
- [COMPETIDOR 2]
- [COMPETIDOR 3]

Dimensiones de análisis:
- Características/capacidades
- Precios
- Audiencia objetivo
- Posicionamiento en el mercado
- Fortalezas/debilidades
- Movimientos recientes

Proporciona:
- Plantilla de matriz de comparación
- Fuentes de información para cada competidor
- Oportunidades de diferenciación
- Evaluación de amenazas
- Recomendaciones estratégicas
```
